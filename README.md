# EcoBazar Organic Store

A responsive grocery storefront recreated from the supplied visual reference using plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Internet access is required for Google Fonts and the remote Unsplash product photography.

## Included
- `index.html` — page structure and content
- `style.css` — responsive styling and layouts
- `script.js` — product rendering, category filters, search, cart drawer, quantity controls, countdown and newsletter demo

## Notes
This is a front-end demo. Checkout, newsletter submission, account links and video are demonstration interactions; connect your own backend/payment provider to make them production services. Replace the sample product data and image URLs in `script.js` with your own catalogue.
